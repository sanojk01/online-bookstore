# 📚 End-to-End Backend Development for Online Bookstore with Authentication System

A full-stack Online Bookstore Management System developed using the MERN Stack (MongoDB, Express.js, React.js, Node.js). The project focuses on secure backend development, JWT authentication, REST API integration, inventory management, cart handling, and order processing.

---

# 🚀 Features

## 👤 Authentication System
- User Registration
- User Login
- JWT Authentication
- Password Encryption using bcrypt.js
- Protected Routes
- Role-Based Access Control (Customer & Seller)

---

## 📚 Book Management
- Add New Books
- Update Book Details
- Delete Books
- Browse Books
- Search Books by Category
- Real-Time Inventory Management

---

## 🛒 Cart & Order Management
- Add to Cart
- Remove from Cart
- Update Cart Quantity
- Place Orders
- View Order History
- Order Status Management

---

## 📦 Inventory Management
- Stock Monitoring
- Inventory Updates
- Out-of-Stock Validation
- Seller Inventory Dashboard

---

## 🔐 Security Features
- JWT Token Authentication
- Password Hashing
- Protected APIs
- Middleware Validation
- Environment Variable Protection
